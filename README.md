# KaraokeNext — instalatory

Publiczne wydania KaraokeNext dla Windows 10/11 (64-bit, x64).

Instalatory są publikowane w [Releases](https://github.com/komar106/KaraokeNext-Releases/releases).
Pobierz plik `KaraokeNext-Setup-X.Y.Z-x64.exe` z wybranego wydania.
Pliki „Source code” zawierają tylko opis tego repozytorium — nie są instalatorem.

Od wersji 0.7.6 w programie: **Ustawienia → Aktualizacje programu → Sprawdź aktualizacje**.
Pobierz nowe wydanie i po zakończeniu występu wybierz **Zamknij i uruchom instalator**.
Aktualizacja zachowuje kolejkę, bazę, filmy i ustawienia. Konto GitHub nie jest wymagane.

Dla wersji starszych niż 0.7.6 pierwszą aktualizację wykonaj dotychczasową metodą.
Wersję przenośną instaluj w osobnym folderze; jej danych nie przenosi się automatycznie.

Repozytorium służy wyłącznie do dystrybucji instalatorów. Projekt źródłowy jest prywatny.
Informacje o zmianach i dołączonych narzędziach znajdują się w opisie danego wydania i w paczce programu.
